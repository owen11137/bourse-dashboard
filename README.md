# بورس‌نما — bourse-dashboard

پنل شاخص‌های بورس ایران، بورس کالا و قیمت جهانی فلزات، با React و Material UI راست‌چین و API آزمایشی Spring Boot 4.1.1.

## اجرای محلی

نیازمندی‌ها: Java 17 یا بالاتر، Maven 3.6.3 یا بالاتر، Node.js 22.12 یا بالاتر.

ترمینال اول:
```bash
cd backend
mvn spring-boot:run
```
ترمینال دوم:
```bash
cd frontend
npm ci
npm run dev
```
صفحه: http://localhost:5173 — مسیر `/` همان صفحه index است.
Vite درخواست‌های `/api` را به بک‌اند روی پورت 8086 هدایت می‌کند.

## بازارهای ایران

صفحهٔ پیش‌فرض شاخص‌های بورس ایران است. از منوی بالای صفحه می‌توانید بورس کالا یا فلزات جهانی را انتخاب کنید. هر بازار جست‌وجو، کارت‌های خلاصه، درصد تغییر نمونه و دکمهٔ دریافت مجدد دارد.

- `GET /api/v1/iran/indices`: چهار شاخص نمونهٔ بورس تهران و فرابورس؛ مقدار شاخص با واحد `point`.
- `GET /api/v1/iran/commodities`: شش محصول نمونه؛ قیمت به ریال بر کیلوگرم (`irr_kg`) یا ریال بر تن (`irr_ton`).

خروجی هر دو مسیر شامل `source`, `demo`, `updatedAt`, `quotes` است. داده‌ها ساختگی‌اند و قیمت رسمی عرضه یا معامله نیستند. برای اتصال دادهٔ واقعی، یک منبع معتبر و جزئیات عرضه (تولیدکننده، گرید، تاریخ و شرایط معامله) لازم است.

## API

`GET http://localhost:8086/api/v1/metals/prices`

خروجی: `source`, `demo`, `updatedAt`, `metals`؛ هر فلز دارای `symbol`, `name`, `category`, `price`, `currency`, `unit`, `changePercent` است.
قیمت فلزات گران‌بها به دلار بر اونس تروا و صنعتی به دلار بر تن متریک است.
قیمت جهانی طلا از BrsAPI دریافت می‌شود؛ `demo=false` و `source=BrsAPI` است. این API در نمونهٔ ارائه‌شده فقط `XAUUSD` را برای فلزات جهانی دارد؛ نقره و فلزات صنعتی نمایش داده نمی‌شوند. مقدار `time_unix` همان رکورد، زمان `updatedAt` را تعیین می‌کند و لحظه‌ای بودن قیمت تضمین نمی‌شود. پاسخ موفق ۶۰ ثانیه در بک‌اند کش می‌شود.

قبل از اجرای بک‌اند، کلید خود را در همان ترمینال تنظیم کنید (کلید را در Git یا فرانت‌اند نگذارید):

PowerShell:
```powershell
$env:BRSAPI_KEY = "YOUR_API_KEY"
cd backend
mvn spring-boot:run
```

Bash:
```bash
export BRSAPI_KEY="YOUR_API_KEY"
cd backend
mvn spring-boot:run
```

بک‌اند از مسیر `https://api.brsapi.ir/Market/Gold_Currency.php` استفاده می‌کند. برای تست محلی با سرور شبیه‌سازی‌شده، `brsapi.url` قابل تنظیم است. کلید خالی پاسخ 503 می‌دهد؛ خطای سرویس یا دادهٔ نامعتبر پاسخ 502 می‌دهد و قیمت ساختگی جایگزین نمی‌شود. در صورت شکست به‌روزرسانی، UI دادهٔ قبلی را با پیام هشدار نگه می‌دارد. در محیط ابری باید دامنهٔ `api.brsapi.ir` مجاز و کلید به‌صورت متغیر محیطی تزریق شود. `HTTPS_PROXY`/`https_proxy` در بک‌اند پشتیبانی می‌شود.

تست‌ها از نمونهٔ JSON ارائه‌شده و یک HTTP server محلی استفاده می‌کنند و به توکن واقعی یا اینترنت نیاز ندارند. شاخص‌های ایران و بورس کالا همچنان دادهٔ نمونه دارند.

## جدول طلا و ارز

بخش «طلا و ارز» تمام داده‌های BrsAPI را در سه جدول طلا و سکه، ارز و رمزارز نشان می‌دهد. مسیر `GET /api/v1/markets/gold-currency` گروه‌های `gold`, `currency`, `cryptocurrency` را با همهٔ فیلدهای منبع برمی‌گرداند. نام فارسی و انگلیسی، نماد، قیمت، واحد، مقدار و درصد تغییر، تاریخ، ساعت و زمان یونیکس در جدول‌ها نمایش داده می‌شوند. برای رمزارزها، ارزش بازار و توضیحات نیز نمایش داده می‌شود و مقدار تغییر غایب از منبع ساخته نمی‌شود. جست‌وجو و فیلتر گروه در دسترس است؛ قیمت‌های کوچک رمزارزها با دقت تا ۱۰ رقم اعشار نمایش داده می‌شوند. این مسیر و قیمت جهانی طلا از یک کش ۶۰ ثانیه‌ای مشترک استفاده می‌کنند. کلید همچنان فقط از `BRSAPI_KEY` در بک‌اند خوانده می‌شود.

## کامودیتی

بخش «کامودیتی» از `https://api.brsapi.ir/Market/Commodity.php` با همان متغیر `BRSAPI_KEY` استفاده می‌کند. مسیر بک‌اند `GET /api/v1/markets/commodity` سه گروه `metal_precious`, `metal_base`, `energy` را با همهٔ فیلدهای منبع برمی‌گرداند و کش مستقل ۶۰ ثانیه‌ای دارد. قیمت، مقدار و درصد تغییر، نام، نماد، واحد پول، تاریخ، ساعت و زمان یونیکس هر ردیف در جدول نمایش داده می‌شود. جست‌وجو و فیلتر گروه فعال‌اند. واحد پول منبع نمایش داده می‌شود؛ وزن یا حجم قرارداد در JSON مشخص نیست و در UI حدس زده نمی‌شود. برای تست با سرور محلی می‌توانید `brsapi.commodity-url` را تنظیم کنید.
